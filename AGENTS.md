# Tectonic production contract

- This is a public artifact. Read `CLAUDE.md` and the latest four briefings
  before drafting or reviewing an issue.
- Run `python3 scripts/briefing-audit.py context --repo . --target-date
  YYYY-MM-DD` before generation and audit the candidate against that manifest.
- Run `./scripts/build.sh --check` before delivery.
- Structural validation is necessary but not sufficient. Complete prose,
  factual, confidentiality, and read-mode review, then wait for Dave's approval.
- Never include private workflow, editorial, peer-review, collaborator, BioOS,
  or unpublished-manuscript state.
- Never publish, commit, or push without Dave's explicit instruction.
